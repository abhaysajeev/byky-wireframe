Package Fare Enter one package time and its fare configuration at a time. The same package time applies to all fare rows below.

Example: 30, 45, 60. This is entered here and selected later during Scheme Creation.
Concurrent Fare
Charge applied after the package time + grace period.
Calculation: Package Time + Grace = Basic Fare. After that, each completed Concurrent Interval adds the Concurrent Price. Example: 30 min + 5 min grace = AED 100. At 38 minutes, one 10-minute concurrent slab is charged → AED 110.
Time Slab Pricing Optional. Enable this only when the selected package needs different fares during different times of the day.
04
Enable Time Slab Pricing
If enabled, multiple daily time slabs can be entered. Basic fare, grace and concurrent price can vary by slab.
Daily Pricing Windows
The package time above remains common; only the time-window pricing changes.
